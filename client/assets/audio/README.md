# SkyGround Offline Audio Matrix

This directory contains offline bundled emergency audio matrices for Greater Accra catchments:
- Twi: `twi_level1.mp3`, `twi_level2.mp3`, `twi_level3.mp3`
- Ga: `ga_level1.mp3`, `ga_level2.mp3`, `ga_level3.mp3`
- English: `en_level1.mp3`, `en_level2.mp3`, `en_level3.mp3`
